# ShopLedger

ShopLedger is a wholesale and retail point-of-sale workshop app for Corner Shop. Staff can place orders, apply coupons, check sellable inventory, bill customers on Khata credit, record settlements, and print GST invoices. Order History and GST Audit let staff review sales and compare invoice figures with the amounts saved at checkout.

## Run locally

Use Node.js 22 or newer and npm for the workshop.

```sh
npm install
npm start
```

Open [ShopLedger](http://localhost:3000). Set the `PORT` environment variable to use another port.

Checkout, cancellations, and Khata settlements write to the tracked `data/db.json` file. Use a temporary project copy when reproducing bugs so the original seed data stays intact. Keep any lockfile generated by `npm install` out of workshop commits.

## Workshop baseline

The seed data contains 12 products, eight historical orders, and five Khata accounts. The project uses Express, a vanilla JavaScript frontend, and a single JSON file for persistence. At this baseline, `npm test` is a placeholder that exits with an error.

The workshop tickets cover three areas:

- Checkout and printed invoices use different GST and discount calculations.
- Requests for exactly the remaining sellable quantity are rejected, and cancellation fails to restore physical stock.
- Order history compares day-first date strings, and Khata settlement amounts can be concatenated as text.
